Animate anything

GSAP is a battle-tested JavaScript animation library. Below is a tour of its core tools and plugins — each one described and shown in action with a live, SVG-powered demo.

Explore the tools ↓

Core

The engine: tweens, timelines, stagger and eases.

gsap.to()

Tween

The atom of GSAP. A tween animates any property of any object over time — position, rotation, scale, color — with smooth interpolation and easing.

gsap.timeline()

Timeline

Sequence tweens with perfect timing. Timelines let you build complex, choreographed animations and control them as a single unit — play, pause, reverse or scrub.

stagger

Stagger

Animate many elements with a single tween, offsetting each one's start time. Grid-aware staggering ripples motion outward from any point for organic waves.

ease

Eases

Easing shapes the feel of motion. GSAP ships a rich set — power, back, elastic, bounce and more — so movement can snap, overshoot or settle naturally.

Scroll

Turn scrolling into silky-smooth storytelling.

ScrollTrigger

ScrollTrigger

The flagship plugin. Tie any animation to the scrollbar — trigger, pin, scrub and snap. The shapes here are scrubbed directly by this card's scroll position. Scroll up and down to drive them.

SVG

Draw, morph and travel along vector paths.

DrawSVGPlugin

DrawSVG

Animate the stroke of any SVG line or path so it appears to draw itself. Perfect for signatures, checkmarks, diagrams and reveal effects.

MorphSVGPlugin

MorphSVG

Seamlessly morph one shape into another, even with differing point counts. GSAP interpolates the vector points to create fluid shape transitions.

MotionPathPlugin

MotionPath

Send any element travelling along an SVG path, automatically rotating it to follow the curve. Great for orbits, routes and playful flourishes.

Text

Leave them lost for words with seamless text effects.

ANIMATE
SplitText

SplitText

Break text into characters, words or lines so each piece can be animated independently. Build dazzling headline reveals with a stagger.

GSAP ROCKS
ScrambleTextPlugin

ScrambleText

Resolve text out of a flurry of random characters for a fun, "decoding" effect — while keeping the element's width perfectly stable.

UI Interactions

Create polished, engaging and accessible interactions.

drag me
Draggable

Draggable

Make any element draggable with momentum, bounds and snapping — across mouse, touch and pointer. Grab the puck and fling it around its box.

Flip

Flip

Animate between any two layout states. Record the start, change the DOM, and Flip smoothly tweens the difference — even across reflows and reorders.
